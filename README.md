# Task Manager Web Application
This is a simple task manager (to-do list) web application built using
HTML, CSS, and JavaScript. The purpose of this project is to practice
basic frontend development concepts and JavaScript DOM manipulation.

## Features
- Add new tasks
- Delete tasks
- Simple and clean user interface
- Works directly in the browser (no backend required)

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
- Users can enter a task in the input box
- Clicking the "Add Task" button adds the task to the list
- Each task has a delete button to remove it from the list
- JavaScript is used to dynamically update the page

## Conclusion
This project helped me understand the basics of frontend web development
and improved my confidence in working with HTML, CSS, and JavaScript.
